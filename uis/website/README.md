# HealthCore Public Website

Public corporate Next.js site for HealthCore — migrated and improved from Milestone 1 (`uis/healthcore-website`) into reusable TypeScript React components.

## Getting started

```bash
cd uis/website
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

- `/` — landing page (hero, services, benefits, contact)
- `/apply` — patient application form with client-side validation

From the monorepo root:

```bash
npm run dev -w website
```
